# StockScan

> An Axum web application whose purpose is to simplify inventory management for businesses while further honing my knowledge of Rust, HTML/CSS, and JavaScript.

# Overview

> StockScan is a web application powered by the Axum framework and a Rust backend. It relies on rusqlite for database management and SQLite for persistent data storage. Its frontend is built using HTML, CSS, and JavaScript, providing an interface for managing products and interacting with the backend through HTTP APIs.

> The project aims to provide businesses with a simple and accessible inventory management solution, allowing them to create, retrieve, update, and delete product records, monitor stock quantities, and organize their inventory efficiently. Future developments include barcode scanning, cashier functionality, user authentication, and a client-server architecture to support more flexible deployment.
